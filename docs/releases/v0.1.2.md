## 사진 용량 줄이기 v0.1.2 (초안 — 아직 올리지 않음)

**일본어·중국어(간체) 화면**을 더한 작은 버전입니다. 줄이는 방법·결과 파일·위치 정보 지우기·새 버전 확인·의견 보내기는 v0.1.1과 같습니다.

### 바뀐 것

- **화면 언어 4개.** 오른쪽 위 언어 목록에 **日本語**와 **简体中文**이 생겼습니다(한국어·English·简体中文·日本語). 고른 언어는 다음 실행 때 그대로 열립니다. 처음 실행할 때는 Windows 표시 언어를 따라 일본어·중국어 Windows에서는 각각 일본어·중국어로 열립니다.
- 일본어 화면은 Yu Gothic UI, 중국어 화면은 Microsoft YaHei UI 글꼴로 그립니다.
- 명령줄도 `--lang ja`·`--lang zh-CN`으로 도움말·진행·오류 문구가 그 언어로 나옵니다.
- **의견 보내기**(ご意見を送る·发送反馈)는 일본어·중국어 화면에서 영어 판 툴 페이지를 엽니다(일본어·중국어 페이지는 없음).
- README 일본어판(README.ja.md)·중국어판(README.zh-CN.md)을 더하고 4개 언어 README가 서로 이어지게 했습니다.

### 확인한 것

- 전체 시험(파이썬 3.12·3.14 각 473개 통과, 알려진 문제 표시 4개 — 새 시험 101개). 새 시험은 언어 파일(한국어와 같은 키·순서·자리표시자, 빈 값·한글 남은 것 없음), 실행 중 언어 바꾸기(한→일→중→영→한, 모든 버튼·표 머리·상태 줄), 최소·기본 창 크기와 화면 배율 100%·150%에서 글자 잘림·겹침, 글꼴에 모든 글자가 있는지, 오류 문구(읽을 수 없는 파일·깨진 HEIC·쓰기 실패·이미 작음·목표 초과·명령줄 실수), 언어와 상관없이 결과 파일이 바이트까지 같은지, 이상한 설정 값·언어 파일이 없을 때를 봅니다. 시험은 실제 브라우저를 열지 않고 네트워크 요청 0건입니다.
- 빌드한 exe 안에 `lang/ja.json`·`lang/zh-CN.json`이 들어 있는 것과, 죽은 프록시 환경으로 띄워 일본어·중국어 창이 뜨고 닫히는 것을 확인했습니다.

### 알려진 것 (v0.1.0부터, 언어와 무관)

- 창을 가장 작게(1000×680) 줄이면 목록 표의 **상태** 열이 오른쪽 밖으로 밀려 보이지 않습니다. 기본 크기에서는 다 보입니다. 이번 판에서는 고치지 않았습니다(시험에 「알려진 문제」로 표시).
