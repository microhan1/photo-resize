## 사진 용량 줄이기 v0.1.3

**의견 보내기**를 책갈피 툴 시리즈와 같은 규칙으로 맞춘 작은 버전입니다. 줄이는 방법·결과 파일·위치 정보 지우기·새 버전 확인은 v0.1.2와 같습니다.

### 바뀐 것

- **키보드로 의견 보내기.** Tab 키로 오른쪽 위 **의견 보내기**에 갈 수 있고, 초점이 오면 글자 뒤가 옅은 파란색으로 칠해져 보입니다(크기는 그대로). Enter나 스페이스를 누르면 마우스로 누른 것과 같이 브라우저로 의견 칸이 열립니다.
- **작은 설명.** 의견 보내기에 마우스를 0.45초쯤 올려 두면 「안 되는 것·불편한 것·바라는 기능을 알려 주세요(브라우저가 열립니다)」가 작게 뜹니다. 마우스를 떼거나 누르면 사라지고, 창을 가장 작게 하거나 화면 끝에 두어도 창·화면 밖으로 잘리지 않습니다. 영어·일본어·중국어 화면에서는 그 언어로 나옵니다.
- **열리는 페이지의 언어 규칙을 하나로.** 한국어 화면만 한국어 툴 페이지를 열고, 그 밖의 모든 언어는 영어 툴 페이지를 엽니다. 의견 보내기와 새 버전 알림의 **업데이트** 둘 다 같은 규칙입니다(지금 고를 수 있는 4개 언어에서는 v0.1.2와 같은 페이지가 열립니다).
- README 영어·일본어·중국어판의 「Chaekgalpi Library」 링크가 영어 툴 페이지로 갑니다.
- 머리줄 Tab 순서를 화면 순서로: **의견 보내기 → 새 버전 확인 → 언어 목록**(Shift+Tab은 거꾸로). 자리와 모양은 그대로입니다.

### 확인한 것

- 전체 시험(파이썬 3.12·3.14 각 731개 중 731개 통과 — 새 시험 199개, 바뀐 규칙과 Tab 순서에 맞춰 고친 기존 시험 5개). 새 시험은 Tab·Shift+Tab 순서, Enter·스페이스가 페이지를 정확히 한 번 여는지, 다른 키는 아무것도 하지 않는지, 초점 표시가 켜지고 꺼져도 크기가 같은지, 설명이 뜨는 때·사라지는 때·4개 언어 문구·실행 중 언어를 바꿀 때, 가장 작은 창을 화면 왼쪽·오른쪽 끝에 둘 때(4개 언어) 설명이 창·화면 안에 있는지, 언어 코드별로 열리는 주소, README 링크를 봅니다. 시험은 실제 키 입력·실제 브라우저를 쓰지 않고 네트워크 요청 0건입니다.
- 빌드한 exe를 설정 파일 없는 임시 폴더에서 죽은 프록시 환경으로 띄워 창이 뜨고 닫히는 것을 확인했습니다(설정 없음·한국어·영어·일본어·중국어 5번, 창 제목 「사진 용량 줄이기 0.1.3」, 서버 접속 0건). exe 안에 4개 언어 파일과 4개 언어의 새 설명 문구가 있고 pillow_heif·x265가 없는 것도 확인했습니다.

**Photo Resize v0.1.3** — **Send feedback** now works from the keyboard: Tab reaches it, the focus shows as a light blue background, and Enter or Space opens the feedback box in the browser like a click. Resting the mouse on it shows a short note (“Tell us what's broken or missing (opens your browser)”, in the screen language) that stays inside the window and the screen. One rule picks the tools page for both **Send feedback** and the new-version **Update** button: the Korean page for a Korean screen, the English page for every other language. The English, Japanese and Chinese READMEs link to the English tools page. The header's Tab order is the order seen: **Send feedback** → update check → language list (Shift+Tab goes back). Shrinking, results, location removal and the update check are unchanged from v0.1.2.
